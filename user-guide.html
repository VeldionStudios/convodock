User Guide

Using ConvoDock

A practical Android guide for setting up ConvoDock, organising captured messages and understanding what the app can and cannot do.

Before you start

ConvoDock is an Android-first, local-first inbox for supported messaging notifications. It works from notification content that Android makes available after you grant notification access.

  • ConvoDock does not import old chat history.
  • ConvoDock does not provide delivery status, read receipts or guaranteed reply delivery.
  • ConvoDock does not sign in to WhatsApp, Messenger, Telegram, Signal, Instagram or other messaging services.
  • ConvoDock cannot show content that the original notification hides.
  • Quick replies work only when the original notification exposes an active Android reply action.

Set up notification access

Open ConvoDock and follow the setup prompts. When Android opens notification-access settings, find ConvoDock and turn its toggle on. This allows ConvoDock to read supported messaging notifications as they arrive.

If messages do not appear, check that the original messaging app is allowed to show message notifications. ConvoDock can only capture notifications that Android receives and exposes.

Choose connected apps

Use the Apps area in ConvoDock to choose which source apps are included. Pausing a source app stops ConvoDock from capturing new notifications from that app. Existing local records remain until you delete them.

Supported-app wording should be treated as notification-derived support. Real-world behaviour can vary by Android version, source app version, notification settings and device manufacturer.

Reduce duplicate alerts

If you allow ConvoDock notifications, ConvoDock can alert you when captured messages arrive. To avoid seeing both ConvoDock alerts and source-app pop-ups, open the source app's Android notification settings and turn off pop-ups or other alert types you no longer want.

This is optional. ConvoDock does not silently change another app's notification settings.

Read the inbox

The Chats screen shows recent notification-derived conversations. Each row can show the sender or group name, source app badge, preview, timestamp and unread count where available.

  • Use search to find locally captured conversations and message text.
  • Use filters such as unread or favourites to narrow the inbox.
  • If an attachment preview is unavailable, open the original app from the message fallback.

Organise contacts and linked identities

ConvoDock lets you build your own local contact list. You can create contacts manually, import phone contacts if you choose, and link source-app identities that belong to the same person.

For example, if one person appears as "Jon" in Messages and "Riggs" in WhatsApp, you can link both identities to one ConvoDock contact. The contact view can then show messages from the linked identities while still indicating which source app each message came from.

  • Use linked identities only when you are sure two source-app identities belong to the same person or group.
  • You can pause a linked identity for a contact without deleting the contact.
  • Contact photos are local to ConvoDock unless they are imported from your phone contacts or exposed by a notification.

Reply or open the original app

When Android provides an active quick-reply action, ConvoDock can send a reply through that original notification. If the action has expired, been cancelled or is unavailable, ConvoDock should offer an "Open in original app" fallback.

Do not treat an in-app reply button as a guarantee that every messaging service supports replies in every situation. Physical-device testing is still the only reliable way to confirm source-app behaviour.

Photos, links and attachments

ConvoDock uses best-effort attachment capture. If Android exposes a readable image or media URI in a notification, ConvoDock can try to copy it into encrypted local storage. If Android or the source app denies access, ConvoDock shows an attachment placeholder and an original-app fallback.

You can also share photos, files and links into ConvoDock manually using Android's share sheet. Manual share imports are more reliable than automatic notification attachment capture because they are started by you.

Privacy controls

Use Settings in ConvoDock to open the privacy policy, delete local app data and manage notification access. Delete all ConvoDock data removes captured messages, copied attachments, contacts and local identity links from the device.

Disconnecting notification access stops future capture but does not automatically delete existing local records. Use the delete controls, clear app storage or uninstall ConvoDock to remove local data.

Trial, purchase and restore

ConvoDock includes a seven-day local trial. The trial does not ask for payment details, does not auto-renew and cannot automatically charge when it ends.

After the trial, full access requires the optional lifetime unlock through Google Play. The intended lifetime price is GBP 4.99, with Google Play supplying the final displayed local price. Use Restore Purchases after reinstalling, clearing app data or changing Android phones.

Troubleshooting

  • No messages appear: enable notification access for ConvoDock and confirm the source app is allowed to show message notifications.
  • Reply is unavailable: open the original app; the notification reply action may have expired or may not be supported by that notification.
  • Duplicate alerts appear: keep ConvoDock notifications on, then turn off source-app pop-ups in Android settings if you want only ConvoDock alerts.
  • Attachment is missing: the original notification may not have exposed a readable preview or file URI.
  • Notification access was revoked: reopen Android notification-access settings and turn ConvoDock back on.
